# 🍽️ MealBridge

### Community Food Sharing & Surplus Reduction Platform

MealBridge is a community-driven food-sharing platform designed to connect people who have surplus food with individuals who need it. The platform aims to reduce food wastage and encourage food sharing within communities.

## 📌 About the Project

A large amount of food is wasted every day while many people struggle to access meals. MealBridge aims to help address this problem by providing a platform where users can share surplus food and request available food.

## 🎯 Project Objectives

- Reduce food wastage.
- Encourage food donation and sharing.
- Connect food donors with people in need.
- Build a supportive and responsible community.

## ✨ Features

Based on the project's existing documentation:

### Authentication
- User registration and login.
- Email and password authentication.
- Protected routes for authenticated users.

### Food Management
- Add surplus food details.
- View available food listings.
- Search food by name.
- Sort food listings by quantity.
- View individual food details.

### Food Request System
- Request available food.
- Add additional notes to food requests.
- View requested food in the user's request section.

### User Dashboard
- Manage donated food.
- View food requests.

### Additional Features
- Responsive user interface.
- Toast notifications.
- Animated UI components.

## 🚀 Installation and Setup

### Prerequisites

- Node.js
- npm
- Git

### Step 1: Clone the repository

```bash
git clone https://github.com/SakshamxChauhan/MealBridge_AP_2026.git
```

### Step 2: Navigate to the frontend directory

```bash
cd MealBridge_AP_2026/Mealbridge
```

### Step 3: Install dependencies

```bash
npm install
```

### Step 4: Start the development server

```bash
npm run dev
```

### Step 5: Open the local website

Visit:

```text
http://localhost:5173/
```
